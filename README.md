# Planilha-de-investimento-imobiliário
Essa planilha foi criada para estudos no curso da DIO.
Nela foi utilizada a fórmula VF para calcular o rendimento dos investimentos com um valor de investimento mensal fixo (a escolha do usuário) e com um percentual constante.
Foi feito também um menu de configurações onde é possível colocar o salario e informar a porcentagem do salario que deseja investir para saber quanto separar e investir mensalmente.
No final da planilha há também um quadro para verificar o perfil de investidor e quanto é recomendado investir em cada tipo de FII.
